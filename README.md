# ModelMirage

Клиентский Fabric-мод для Minecraft 26.2. Сейчас в нём одна модель предмета — **Blood Axe Mace**, которую можно поставить на любой предмет. Сервер видит стандартные предметы.

Нажми **Right Shift** в мире. Найди и выбери предмет, затем модель, и нажми **Применить**. **Сбросить** возвращает обычную модель выбранного предмета. Выбор сохраняется в `config/modelmirage.json` и действует только на отображение в клиенте. Переключение уже загруженной модели происходит сразу, без перезагрузки ресурспаков.

Пока модель и её текстура входят в JAR. Загрузка новых моделей из сети и каталог будут отдельным этапом; текущая сборка не загружает новые файлы в память во время игры.

## Сборка

Нужен JDK 25. Запусти `JAVA_HOME=/usr/lib/jvm/java-25-openjdk ./gradlew build`; готовый JAR появится в `build/libs/`. Для проверки в клиенте запусти `JAVA_HOME=/usr/lib/jvm/java-25-openjdk ./gradlew runClient`.

## Тесты через Minecraft Mod MCP

Запусти `./scripts/setup-mcp.sh`: скрипт скачает проверенный JAR Minecraft Mod MCP 0.4.1 для Fabric 26.2 в `run/mods/`. Bridge для MCP-совместимых агентов описан в `.mcp.json`; ему нужен Node.js 20+. В текущей тестовой среде скриншоты через MCP работают, а команды нажатия и клика не управляют GUI (`hook: false`); для интерактивной проверки использован Xvfb с `xdotool`.
